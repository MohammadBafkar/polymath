# polymath-leadership

Leadership craft for the Polymath marketplace.

## What it ships

- Skills: `one-on-one-prep`, `perf-review`, `okr-setting`, `hiring-loop`, `conflict-mediation`, `coaching-plan`.
- Templates: `1-on-1.md`, `Perf-review.md`, `OKR.md`.

`hiring-loop` (structured interview design + debrief), `conflict-mediation` (positions→interests, difficult conversations), and `coaching-plan` (forward-looking growth + sponsorship) cover the people-leadership gap alongside the existing evaluation/alignment skills.

## Installation

```bash
claude plugin install polymath-leadership@polymath
```

## Dependencies

- `polymath-core`
