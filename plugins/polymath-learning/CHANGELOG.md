## [0.11.0]

### Changed

- `feynman-technique`: when coaching a person, they write the attempts — the agent marks cracks.
- `explain`: inferred tier when unstated; wording fix.

## [0.8.0]

Learning craft: tiered explanations, code walkthroughs, Feynman-style self-test.

### Skills

- **code-walkthrough** — Explain a piece of code in execution order — entry point, branches, side effects, the surprising line; cite file:line; not a line-by-line rewrite.
- **explain** — Explain a concept at a specified audience tier (ELI5 / curious-undergrad / experienced-peer / domain-expert); pick the analogy and abandon it before it lies.
- **feynman-technique** — Verify your understanding of a concept by attempting an undergrad-level explanation; surface exactly where the explanation cracks and study those.
